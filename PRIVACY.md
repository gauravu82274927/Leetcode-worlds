# Privacy Policy for LeetCode Worlds

**Last updated:** November 8, 2026

LeetCode Worlds is a Microsoft Edge extension that changes the appearance of the LeetCode website with original visual themes and personalization options.

## Information collection

LeetCode Worlds does not collect, transmit, sell, or share personal information.

The extension does not use analytics, advertising trackers, cookies, external databases, or user accounts.

## Information stored locally

The extension uses Microsoft Edge’s local storage to save:

- Selected theme
- Enablement, focus mode, and motion preferences
- Accent and surface colors
- An optional custom background image selected by the user

This information remains on the user’s device and is not sent to the extension developer or any third party.

## Website access

The extension runs only on pages matching:

`https://leetcode.com/*`

It changes the visual presentation of LeetCode pages and does not read, collect, or transmit passwords, submissions, code, messages, payment information, or other personal content.

## Custom images

If a user selects a custom background image, the image is resized when necessary and stored locally in the browser. It is not uploaded to any server.

## Permissions

The extension requests the `storage` permission solely to save user preferences and optional custom background settings locally.

## Changes to this policy

This privacy policy may be updated if the extension’s functionality changes. The latest version will be available in this repository.
