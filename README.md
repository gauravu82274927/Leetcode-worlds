# LeetCode Worlds

LeetCode Worlds is a Microsoft Edge extension that adds original anime-inspired themes to LeetCode, helping you create a calmer and more motivating coding environment.

## Features

- Four built-in worlds:
  - Sakura Dojo
  - Cyber Tokyo
  - Samurai Arena
  - Anime Study Room
- Optional custom PNG, JPEG, or WebP background
- Accent and surface color controls
- Focus mode to hide scenery while keeping useful interface accents
- Optional ambient motion
- Editor-safe styling designed to avoid interfering with code editors
- Settings saved locally in the browser
- No account, analytics, tracking, or external server required

## Installation from Microsoft Edge Add-ons

Install the extension from the Microsoft Edge Add-ons store when it becomes available.

## Install locally for development

1. Download or clone this repository.
2. Open Microsoft Edge and go to `edge://extensions`.
3. Turn on **Developer mode**.
4. Select **Load unpacked**.
5. Choose the `extension` folder.
6. Open [LeetCode](https://leetcode.com/) and select the LeetCode Worlds icon to choose a theme.

## Permissions

LeetCode Worlds requests only the `storage` permission. This is used to save your selected theme, preferences, colors, and optional custom background locally in Microsoft Edge.

The extension runs only on:

`https://leetcode.com/*`

## Privacy

Your settings and custom background are stored locally on your device. The extension does not collect, transmit, sell, or share personal information.
